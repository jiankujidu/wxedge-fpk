# 网心云容器魔方（wxedge）飞牛 fnOS 应用

一键在飞牛 fnOS 上部署网心云容器魔方（wxedge），自动拉取官方镜像、开机自启，桌面入口直达管理页面。

## 功能特性

- Docker Compose 自动部署（fnOS 应用中心接管容器生命周期，开机自启）
- 数据目录自动创建于应用安装的存储空间（文件管理 → 应用文件 → wxedge/data）
- host 网络 + 特权模式，符合网心云收益要求
- 桌面图标一键打开激活/管理页面（IP:5316）
- 卸载保留数据（应用文件目录不删除）

## 安装

1. 飞牛 fnOS → 应用中心 → 右上角「手动安装」→ 选择 `wxedge-1.0.5.fpk`
2. 在安装向导中选择应用的**存储空间**（建议容量充足、读写快的存储空间，独立 SSD 效果更佳，网心云收益与存储性能相关）
3. 等待自动部署（首次拉取镜像约几分钟）
4. 桌面出现「网心云」图标，点击打开激活页面

> 数据目录位于 `文件管理 → 应用文件 → wxedge/data`，对应容器内 `/storage`。

## 激活与绑定

1. 打开应用（或浏览器访问 `http://<NAS IP>:5316`）
2. 页面初始化完成后显示激活二维码
3. 手机下载「网心云」App，右上角「+」→ 扫一扫，扫码绑定设备
4. 绑定成功后自动贡献闲置带宽，收益在网心云 App 中查看

## 使用与管理

- **查看状态**：应用中心「网心云」→ 打开，即设备管理页面（在线状态、带宽、收益）
- **启停**：应用中心可点停止/启动（系统自动 `docker compose` 管理容器）
- **更换存储位置**：卸载后重新安装并选择其他存储空间（旧数据保留，可在文件管理中迁移）

## 升级

应用中心检测到新版本后升级即可，数据目录不受影响。

## 卸载

卸载会停止并移除容器，**不会删除**应用文件目录中的数据（设备标识、缓存等），如需彻底清理请手动删除 `文件管理 → 应用文件 → wxedge`。

## 常见问题

- **镜像拉取慢/失败**：默认使用国内镜像源 `images-cluster.xycloud.com/wxedge/wxedge:latest`，若失败可先在 Docker 终端手动 `docker pull` 后重试
- **容器启动失败**：应用中心查看错误日志；确认 Docker 已安装且运行中
- **打不开 5316 页面**：确认应用状态为「运行中」，浏览器访问 `http://<NAS IP>:5316`
- **收益低**：建议检查 NAT 类型（全锥型最佳）、上行带宽占用、存储是否为独立 SSD

## 构建

```bash
# 需要 fnpack（下载: https://static2.fnnas.com/fnpack/fnpack-1.2.3-linux-amd64）
./build.sh
# 产物: wxedge-1.0.6.fpk（由 fnpack 生成 wxedge.fpk 后自动改名）
```

## 目录结构

```
wxedge-fpk/
├── manifest            # 应用元信息
├── ICON.PNG            # 图标 64x64
├── ICON_256.PNG        # 图标 256x256
├── cmd/                # 生命周期脚本（docker 应用由 appcenter 启停）
├── config/             # privilege（docker-wxedge 用户）+ resource（docker-project + data-share）
├── wizard/             # 安装向导（存储说明）
├── app/
│   ├── docker/         # docker-compose.yaml（host 网络 + privileged）
│   └── ui/             # 桌面入口（5316）
└── build.sh
```
